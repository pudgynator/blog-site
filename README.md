This is a training project for learning Next.js. It is a small blog site with a home page, an about page, a list of recent posts, and a page for each post.

Posts come from the [JSONPlaceholder](https://jsonplaceholder.typicode.com) API. The list links to `/posts/[id]`, and a spinner shows while a page is still loading its data. The layout includes a header, a footer, and styles that change with the screen size.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
